# NAGOYA RUN — 名古屋ハーフ完走に向けた記録アプリ（試作 v0.1）

## 目的
2027年3月14日の「名古屋シティマラソン2027」ハーフマラソン（21.0975km）の完走に向け、iPhoneで手入力の運動記録をつけるための軽量なPWA（Webアプリ）。フレームワーク・有料API・ログイン・通知・バックアップは不要。

## ファイル構成
- `index.html` — 画面・記録・集計・XP・判定ロジックすべて
- `manifest.webmanifest` — iPhoneホーム画面起動用の設定
- `sw.js` — 初回読み込み後のオフライン表示用キャッシュ
- `icon-192.png` / `icon-512.png` — アプリアイコン

## iPhoneで使うまで
1. ZIPを展開して、同一フォルダにある5ファイル（HTML / manifest / Service Worker / アイコン2枚）を **HTTPS対応の静的Webホスティング** にアップロードする（GitHub Pages / Cloudflare Pagesなど）。**サーバー側のプログラムやビルド作業は不要**。
2. 配置したURLをiPhoneのSafariで開く。
3. Safariの共有メニューから「ホーム画面に追加」。
4. 作成されたホーム画面アイコンから起動して使う。記録は以後そのアイコンから入力する。

**注意**：ZIPをiPhoneに保存しただけではホーム画面アプリとして自動起動しない。URLへの公開（非公開運用ならアクセス制限付きのHTTPS配置）が必要。`file://` で開いたHTMLは保存やオフライン対応が正常に動作しない場合がある。

## 搭載機能
- 手入力：日付・距離(km)・時間(分)・疲労感(1〜5)・メモ・休息日
- 同日の記録編集・削除（過去に獲得したXPは維持）
- ローカル保存：端末の `localStorage`（クラウド送信なし）
- 月曜日始まりで直近4週間を集計、累計距離・運動日数・最長距離
- 前日比（両日とも運動記録がある場合）、前回比、前週の1回平均距離との比較
- 最大5目標：各枠に自由な名前・数値を設定。対応指標：当日の距離・時間・ペース、週の運動回数・合計距離・1回平均距離・1回平均時間・加重平均ペース
- 目標1件達成ごとに20XP、1日最大100XP。各目標枠は同じ日には1回のみ。同一週の週次目標もその週に1回のみ
- 目標変更時も既獲得XP保持。レベル = 1 + floor(累計XP / 200)。上限なし
- 休息曜日を選択、連続達成記録への扱い（継続維持・カウント・途切れ）を設定
- 連続達成のみリセット（運動履歴・XP・獲得済みバッジは維持）。バッジは20、40、60、80、100連続達成
- 名古屋ハーフに対するコメント：大会までの日数、過去最長距離、最近の運動頻度、第1関門のペース参考、疲労、同程度距離の前回ペース比較

## 2027年公式大会の基準
- 開催：2027-03-14（日）、10:20号砲
- 距離：21.0975km、制限：号砲から3時間、スタート閉鎖：10:40
- 関門：6.0km＝11:23、10.4km＝11:55、15.7km＝12:35、ゴール＝13:20
- スタート線通過が10:40だった場合、最初の6kmに必要な平均ペースは **7分10秒/km**。実際のスタート線通過時刻によって必要ペースは変わる
- 3時間÷21.0975km≒**8分32秒/km** は「号砲と同時にスタートでき、関門の問題がない場合」の単純平均にすぎない。実際には関門が先に制約になる
- 公式コース：バンテリンドーム ナゴヤ→桜山・堀田付近を折り返し→日銀前・伏見方面→白川公園。コース高低図は比較的緩やかなアップダウン

## 評価基準の設計
- **距離（基礎）**：0〜3kmは「継続できる運動習慣」重視、3km / 6.0km / 10.4km / 15.7km / 21.0975kmの過去最長距離到達を節目としてコメント
- **ペース（関門参考）**：直近1回の走行距離が6km以上の場合だけ、最後尾近くのスタートを仮定した最初の6km目安 **7:10/km** と比較。これができても公式完走を保証するわけではない
- **継続性（過去の自分）**：直近14日の運動回数。0〜1回／2〜5回／6回以上でメッセージ分岐
- **疲労**：自己申告4〜5で回復優先の注意を出す
- **過去実績比較**：直近と前回がほぼ同距離（誤差±15%）なら平均ペースを比較（10秒/km以上の差を変化として扱う）
- **時期**：大会まで残り60日以下、21日以下の条件で練習量への注意を表示

※ 完走確率や単一の「準備率」は算出しない。過去最長距離が大会距離に占める割合は表示するが、完走の見込みとは明確に区別する。

## 初期設定（変更可能）
- 目標枠①：週3回走る
- 目標枠②：1回20分動く
- 目標枠③：1回3km動く
- 目標枠④⑤：未使用

これは大会完走を保証する最低運動量ではなく、無理なく記録を始めるための仮設定。

## 初期版として割り切った点
- HTTPS配置作業はユーザー側で必要（未デプロイ）
- データはブラウザ保存領域に依存。アプリ/サイトデータ削除・端末故障で消える可能性あり（バックアップなしの方針）
- 目標は「自由な名前＋8種類の計算指標＋任意数値」で設定。独自の数式入力は現時点では非対応
- 予定休息曜日は週単位の固定設定。日ごとに変える場合は休息日の記録を残す
- 目標変更しても過去の実績値やXPを遡って再計算しない
- 厳密な完走判定には実際の号砲時刻・スタート線通過時刻・給水・混雑・気候などが必要なため、練習データだけでは算出しない
